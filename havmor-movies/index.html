Overview

This app is no longer functional — the API it depended on is no longer available.

Havmor Movies is an Angular web app for quickly finding the latest YIFY movie torrents, inspired by Popcorn Time 🍿. New releases appeared in the app as soon as the YIFY database updated, and detailed movie information was pulled from a third-party movie API 🧠.
