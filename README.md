# Keshav Reddy Lingala 👨‍💻

Personal portfolio — a single-page site plus 17 project write-ups, built with
**Astro 5** (static output) and deployed to **GitHub Pages** at
[keshav.codes](https://keshav.codes).

[![Portfolio](https://img.shields.io/badge/open-keshav.codes-gold)](https://keshav.codes)
[![Deploy](https://github.com/keshavlingala/keshavlingala.github.io/actions/workflows/build_astro.yml/badge.svg)](https://github.com/keshavlingala/keshavlingala.github.io/actions/workflows/build_astro.yml)

## Getting started

Requires Node >= 18 (CI uses Node 20).

```bash
npm install
npm run dev        # dev server on http://127.0.0.1:4321
npm run build      # static build to ./dist
npm run preview    # serve the built ./dist
npm run typecheck  # astro check
```

## Project layout

```
src/
  pages/       index.astro, [slug].astro, 404.astro + machine-readable endpoints
  layouts/     Base.astro (shell + SEO), PostLayout.astro
  components/  Hero, Nav, Experience, ProjectsLog, SkillGalaxy, Contact, Footer, …
  content/     posts/<name>/index.mdx with colocated images/, plus icons + images
  data/        experience.ts, skills.ts — drive the Experience and Skill sections
  lib/         markdown.ts (plain-text renderings), schema.ts (JSON-LD)
  scripts/     skill-galaxy.ts — interactive skill visualization
  styles/      global.css (components use scoped <style> blocks)
public/        copied verbatim into dist/ — CNAME, manifest, robots.txt, icons, gifs
```

### Content

Project write-ups are an Astro content collection defined in
`src/content.config.ts`. Each one lives in `src/content/posts/<name>/index.mdx`
with its images beside it, and renders at `/<slug>` through
`src/pages/[slug].astro`. Frontmatter carries `title`, `date`, `description`,
`tags`, `techs`, `featuredImage`, and optional `code` / `code2` / `demo` links.

### Machine-readable twins

Every page has a plain-markdown counterpart for LLM crawlers and agents,
generated by `src/lib/markdown.ts`:

| Route | What it is |
| --- | --- |
| `/llms.txt` | [llmstxt.org](https://llmstxt.org) index of every page |
| `/llms-full.txt` | the whole site as one document |
| `/about.md` | profile, experience and skills |
| `/<slug>.md` | any project write-up as markdown |

Pages advertise their twin with `<link rel="alternate" type="text/markdown">`
(the `markdown` prop on `Base` / `SEO`), `public/robots.txt` points at them, and
the sitemap filters `.md` / `.txt` routes out.

### Other bits

- `@vite-pwa/astro` generates and registers the service worker; the manifest is
  hand-written at `public/manifest.webmanifest`. Demo gifs (2–21 MB) are excluded
  from precaching and cached on first view instead.
- The contact form posts to a Railway-hosted mailing service
  (`src/constants.ts`).
- Site-wide metadata — name, tagline, description, social links — lives in
  `src/site.ts`.

## Deployment

`.github/workflows/build_astro.yml` runs on every push to `main`: `npm ci` →
`npm run build` → publish `./dist` to the `gh-pages` branch via
`peaceiris/actions-gh-pages`. The custom domain works because `public/CNAME`
ends up in the build output — don't remove it.
